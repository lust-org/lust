on(sig, callback)
  Calls callback(sig) when signal sig ("SIGINT", "SIGTERM", ...) arrives;
  nil restores the handling before. It runs before the next Lua
  instruction (a blocking call continues first; a JIT-compiled loop
  calling no C function runs on until it exits) and its errors are raised
  there. Signals arriving before it ran call it once. Not for faults
  (SIGSEGV, ...), SIGABRT, SIGKILL, SIGSTOP. Only one Lua state of a
  process can have callbacks

number(sig): number
  Number of signal sig ("SIGTERM": 15; any name proc.run reports, e.g.
  "SIGRTMIN+2"); 128 + number is a shell's status for a program it killed
