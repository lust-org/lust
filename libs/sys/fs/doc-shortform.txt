Conventions:
  Every function returns nil, "<path>: <reason>", "<errno name>" (e.g.
  "ENOENT") on failure (missing file, no permission, ...); wrong
  arguments or opts raise. Types of files: "file", "directory", "link",
  "fifo", "socket", "char", "block", "other". A mode: permission bits,
  e.g. tonumber("755", 8)

read(path): str
  Contents of file path

write(path, str [, opts]): true
  Writes str to file path, created (mode 0666 minus the umask) or
  emptied. opts: append (add to its end instead), atomic (readers, and a
  crash, see the old or the new contents, never a part: writes a new file
  next to it, renamed over path; it keeps path's mode, a link stays)

list(path [, opts]): {name, ...} [, {type, ...}]
  Entries of directory path, without . and .., unordered. opts: types
  (also return their types, as the directory reports them: no stat)

walkdir(root [, opts]): iterator, state
  for dir, name, type in walkdir(root) do: everything below root, depth
  first, a directory before its contents (each unordered), links not
  followed. dir: root as given, or dir .. "/" .. name of a directory
  yielded before; join them only where needed (the costly part). A
  directory that cannot be listed raises when reached (unless it
  vanished). opts: max_depth (1: root's entries only), prune
  (function(path): true skips that directory's contents), on_error
  (function(path, err, code), called instead of raising)

stat(path [, opts [, t]]): t
  Fields: type, size, mode, mtime, atime, ctime (seconds since the epoch,
  with fractions), uid, gid, nlink, ino, dev. opts: follow (default true;
  false: a link itself). t: the table to set all fields in (other keys
  kept, untouched on failure), default a new one; reusing one in a loop
  halves the cost

readlink(path): str
  Target of the symbolic link path

realpath(path): str
  Absolute path of path, without symbolic links, "." and ".."

getcwd(): str
  The working directory ("ENOENT" if it was removed)

chmod(path, mode): true
  Sets the mode of path (following links)

mkdir(path [, opts]): true
  Creates directory path. opts: mode (default 0777 minus the umask),
  parents (create missing parents; an existing directory is no error)

tempfile([opts]): path
  Creates a new empty file only the user can access (mkstemp); open it
  with io.open(path, "w+"). opts: dir (default $TMPDIR or /tmp), prefix
  (default "lust-"), suffix

tempdir([opts]): path
  The same for a directory (mkdtemp). opts: dir, prefix
