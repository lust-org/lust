spawn(argv [, opts]): child | nil, err, code
  Starts program argv[1] with the arguments argv[2], ... (no shell; found
  in PATH unless it contains "/"; "ENOENT": not found). It gets no
  descriptors but 0, 1, 2. opts: stdin, stdout, stderr ("inherit"
  (default), "null", "pipe" or a file from io.open), input (a string
  wait feeds to stdin), cwd, env (a copy of ours with name = value set,
  name = false removed), session (true: it leads a new session, without
  our terminal). A collected child runs on (and is reaped).
  child.stdin, child.stdout, child.stderr: a stream for each "pipe"
  child:wait(): status, stdout, stderr: closes stdin, reads the output to
    the end, waits for the exit. status: the exit code, or the signal
    that killed it ("SIGKILL"); stdout, stderr: the unread rest ("", nil
    unless piped). Again: the same status.
  child:kill([sig]): true | nil, err, code: sends sig (default
    "SIGTERM"; to the whole group if it leads a session). "ESRCH" once
    waited for.
  stream:read([fmt]): data | nil: "l" (default) a line without "\n",
    "a" all to the end ("" there), n what is there, at most n bytes
    (waits only if nothing is). nil at the end.
  stream:lines(): iterator over the lines
  stream:write(...): true | nil, err, "EPIPE": writes all the strings
    and numbers; "EPIPE" if the child doesn't read any more (no SIGPIPE)
  stream:close(): ends the child's stdin (or stops reading its output)

run(argv [, opts]): status, stdout, stderr | nil, err, code
  spawn(argv, opts):wait(), but stdout and stderr default to "pipe"

poll(list [, timeout]): ready
  Waits until one of the output streams or children in list is ready (a
  stream's read won't wait, a child exited), at most timeout seconds
  (default: no limit). Returns the ready ones, in the order of list ({}
  after the timeout).

exec(argv [, opts]): nil, err, code
  Replaces this process with program argv[1] as spawn would start it
  (the same pid; Lua's buffered output is written first), e.g. as the
  last step of a wrapper. Returns only if that fails. opts: cwd, env
